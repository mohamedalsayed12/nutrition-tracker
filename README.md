# Nutrition Tracker

A Flask app for recording meals and activity, estimating calorie targets, and viewing nutrition targets.

## Local setup

1. Create and activate a Python virtual environment.
2. Install the packages in `requirements.txt` with `pip install -r requirements.txt`.
3. Create a `.env` file with `FDC_API_KEY`, `API_NINJAS_KEY`, and `SECRET_KEY` as needed. The app also reads `password` for the email verification helper.
4. Run `python app.py`.

Local environment files and SQLite databases are excluded from Git.
